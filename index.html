How it works: files are identified by their magic bytes, then checked for mismatched extensions, trailing or embedded payloads, macros, scripts, packers, entropy and suspicious strings. URLs are analyzed structurally for phishing and malware tricks. Results are heuristics, not proof of malware, and a clean result is not a guarantee. Live reputation databases need a server, so the result cards link out to them using only a hash or URL. This tool is not antivirus. Only scan files you own or may analyze.
